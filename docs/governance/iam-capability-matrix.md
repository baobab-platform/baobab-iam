# IAM Capability Matrix

This matrix is the authoritative migration baseline for the Baobab IAM capability boundary. It separates Baobab-owned identity meaning from Ory/Keycloak implementation mechanics and is intended to remain stable through the migration and any future provider replacement.

## Authority and boundary

- Baobab-owned meaning lives in the Shared catalogue and Control Plane resolution model.
- IAM owns the provider-neutral port and the implementation mechanics required to satisfy those capabilities.
- Ory/Keycloak implementation details remain below the boundary and must not leak into Baobab digital estate contracts.
- Business authorization and tenant/legal-entity authority remain outside IAM and are decided by the Control Plane and domain engines.

## Notes

1. This matrix should be treated as a living baseline rather than a one-time document. The canonical decision still belongs to the Accepted ADRs and the Shared catalogue.
2. The `identity.authentication.perform` and `identity.workload-token.issue` capabilities are the clearest provider-neutral contracts already stabilized in this repository.
3. The migration should continue by proving the remaining capability rows behind the same provider-neutral ports rather than by creating Ory- or Keycloak-specific business semantics.
